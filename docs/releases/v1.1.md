# MacVolvo 1.1

<!-- minimum-macos: 26.5 -->

Steam window restoration and session cleanup for the original DXMT app.
Version **1.1, build 9**. The GPTK4 evaluation remains a separate download.

## What's new

- Open Steam requests Steam's main window, including when the client is hidden in the tray while a game runs.
- The launcher leaves Steam's window request in control of focus instead of activating Deadlock again afterward.
- Reopening an existing Steam session avoids the fresh-launch window timeout; an exited client or failed request now produces an error.
- Open Steam repairs an idle client's browser helper after Steam updates replace it, addressing the captured black-window case.
- Temporary Steam game-launch requests are waited for and reaped; closing Steam also ends and waits for its remaining Wine services. Running-game checks protect gameplay during normal cleanup.

## Download and update

Download **MacVolvo-1.1.dmg** from this release. Finish your game, quit Steam
and the MacVolvo launcher, then drag **MacVolvo.app** to Applications and replace
the older app. Open the installed copy. Existing games, Steam sign-in, launcher
preferences and the game environment are retained; reinstalling Steam or
downloading games again is not required.

The app and DMG are Developer ID signed, Apple notarized and stapled. Verify the
download using the attached `.dmg.sha256`; the validation JSON records the
runtime hash, notarization submissions and checks.

Requirements: Apple Silicon, macOS 26.5 or later, Rosetta, a Steam account and
internet access. This release uses the same signed DXMT/Wine runtime archive
as MacVolvo 1.0. Existing v1.0 and GPTK4 installers remain available.

## Known issues and validation limits

**Deadlock's UI/click-position misalignment after changing video settings is
still unresolved.** The reported quarter-screen rendering was not reproduced
by synthetic display tests. Recovery to try: close Deadlock, disable its
Fullscreen option in MacVolvo, choose a resolution that fits the display and
relaunch. Removing `-fullscreen` only in Steam Properties can be undone when
MacVolvo reapplies its saved choices.

Intermittent black-screen launches, audio crackling, CS2 combat spikes and
Deadlock post-match camera/input failures remain under investigation. For
audio crackling, the previously tested workaround is a supported 96 kHz output
format in Audio MIDI Setup followed by a game restart; MacVolvo does not change
system audio settings.

Validation: 137 portable regression tests, Swift launch-readiness checks and
ten synthetic DXMT display-change checkpoints passed. The Steam request path
is covered with native disposable stubs; the remote reporter's complete case
and full-match behavior have not been verified. No FPS improvement is claimed.

See the [investigation notes](https://github.com/haeli05/MacVolvo/blob/v1.1/docs/DEADLOCK-SETTINGS.md)
for evidence and remaining reproduction work.
