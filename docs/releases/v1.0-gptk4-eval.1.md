# MacVolvo GPTK4 — evaluation 1

<!-- minimum-macos: 26.5 -->

A separate, free evaluation app for comparing Apple's **D3DMetal 4.0 beta 3**
with the original MacVolvo's DXMT renderer. App version 1.0, build 8.
The original [MacVolvo 1.0 download](https://github.com/haeli05/MacVolvo/releases/tag/v1.0)
remains available as before.

## What's new

- A separate MacVolvo GPTK4 app, Steam installation, preferences and game library.
- DirectX 11 rendering through Apple's matching D3DMetal 4.0 beta 3 components.
- Steam browser rendering fix and recovery when a Steam update replaces its helper.
- Wine process cleanup after Steam exits and after temporary game-launch requests.
- Correction for Deadlock fullscreen windows left larger than the display after a
  resolution change. This handles the observed zoomed, cropped image.

## Download and install

Download **MacVolvo-GPTK4-1.0.dmg** and its `.sha256` file from this release.
Drag **MacVolvo GPTK4.app** to Applications and open it. Quit an older GPTK4
launcher before replacing it, and finish any game before restarting its Steam.
The app and DMG are Developer ID signed, Apple notarized and stapled.

Requirements: Apple Silicon, macOS 26.5 or later, Rosetta, a Steam account and
internet access. Apple components are distributed for non-commercial evaluation
on Apple-branded systems under Apple's accompanying license.

This app sets up its own Steam. Sign in there and install games into that library.
There is no in-app import button yet; existing games are not imported automatically.
The developer's local APFS-clone import does not run automatically for downloads.

If Steam's first self-update leaves its window black, select **Open Steam** in
the GPTK4 launcher to reopen it with the browser rendering fix.
Keep the launcher open for normal use; the display correction runs with Steam.

## Validation and limits

DirectX 11 GPU texture rendering/readback passed with the imported Apple framework
mapped and DXMT absent. The observed Deadlock crop was corrected from a
3024×1964 window to its 1920×1200 display; the player confirmed the full image.
Automated geometry checks and disposable Win32 window tests cover the correction
and its opt-in behavior.

No comparative FPS or stutter improvement is claimed. Full-match stability,
post-match mouse input and CS2 gameplay with this renderer still need evaluation.
The original app's known launch, audio and performance limitations may still apply.
This DX11 experiment does not use the DX12-only Metal 4 backend.

See [implementation and evaluation notes](https://github.com/haeli05/MacVolvo/blob/v1.0-gptk4-eval.1/docs/GPTK4-EVALUATION.md) for build and test details.
